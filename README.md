# S0lux · 个人博客

一个**双击即可使用**的个人博客：左侧个人资料栏、文章列表、文章详情（目录 / 阅读进度 / 上一篇下一篇）、归档、关于，以及可以**在网页里直接写 Markdown 文章**的写作台。

> 纯前端实现，无数据库、无框架、无 CDN 依赖，断网可用。所有内容保存在浏览器本地（`localStorage`），可一键导出 / 导入 JSON 备份。

## 一、打开与浏览

双击 `index.html`，用 Chrome / Edge / Safari 打开。

首次打开会看到你的资料（站点名「S0lux」，作者陈鑫）和 3 篇开场文章：一篇自我介绍、一篇站点说明、一份学习清单。左上角「设置」可以随时修改。

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 首页 | `#/` | 个人简介、置顶文章、文章列表、标签筛选、搜索 |
| 文章 | `#/p/文章id` | 正文、目录、阅读进度、复制链接、上一篇 / 下一篇 |
| 归档 | `#/archive` | 按年份分组的全部文章 |
| 关于 | `#/about` | 个人简介、所在地、邮箱、社交链接、站点说明 |
| 写作台 | `#/manage` | 全部文章与草稿，新建 / 编辑 / 删除 |
| 编辑器 | `#/write`、`#/write/文章id` | 写标题、摘要、标签、日期、正文，实时预览 |

窄屏（手机 / 平板）下左侧栏会收进抽屉，点左上角菜单按钮打开。

## 二、写一篇文章

1. 左侧「写文章」或写作台右上角「＋ 新建文章」。
2. 填标题、日期、标签（逗号分隔）、摘要（可留空，列表会自动截取正文开头）。
3. 在 Markdown 编辑器里写正文；顶部工具栏可以快速插入标题、加粗、引用、列表、代码块、链接、分割线。
4. **自动保存**：停止输入约 0.5 秒后写入本地，右上角显示「已保存 · 时间」。草稿也是自动保存的。
5. 「存草稿」保存并回到写作台；「发布」保存并把文章公开到首页、归档。
6. 打开编辑器时按 `Ctrl / Cmd + S` 立即保存。
7. 写作台里每篇文章右侧有「编辑」和「删除」两个按钮；删除前会二次确认。

### 支持的 Markdown

| 语法 | 效果 |
| --- | --- |
| `## 标题` / `### 小标题` | 生成章节，自动进入右侧目录 |
| `**加粗**` / `*斜体*` / `~~删除线~~` | 行内强调 |
| `` `代码` `` | 行内代码 |
| ` ``` ` 或 `~~~` 包裹 | 代码块（带语言标签与复制按钮） |
| `> 引用` | 引用块 |
| `- 列表` / `1. 列表` | 无序 / 有序列表，缩进两个空格可嵌套 |
| `[文字](链接)` / `![说明](图片地址)` | 链接、图片 |
| `---` | 分割线 |
| `\| 表格 \|` | 表格（第二行写 `\| :--- \|` 控制对齐） |

正文中单个换行会渲染为换行；空行分段。

## 三、改成你自己的博客

左上角「设置」（移动端在抽屉底部）可以修改：

- 头像（自动裁成方形、压缩到 320px）、站点名称、姓名、身份、一句话介绍、所在地、邮箱、个人简介
- 社交链接（最多 6 个）：有网址的显示成链接，没有网址的账号（微信、QQ、抖音等）会以文字显示在「关于」页
- 主题色：墨蓝 / 松绿 / 赭石 / 胭脂
- 显示模式：浅色 / 深色 / 跟随系统（侧栏底部的三个小图标也可以快速切换）
- 数据：导出备份、导入备份、恢复示例

侧栏和首页会实时更新；关闭设置后整页刷新为最新资料。

## 四、数据与备份

- 数据保存在当前浏览器的 `localStorage`：`blog.site.v1`（资料与文章）、`blog.ui.v1`（主题偏好）。
- 换浏览器、换电脑、清除浏览器数据后，内容不会跟着走。
- 用「设置 → 导出备份」下载 `博客备份-日期.json`，在新设备「导入备份」即可恢复。
- 导入会覆盖当前内容，会先弹窗确认；「恢复示例」也会二次确认。
- 草稿不会出现在首页与归档，只出现在写作台，方便先写后发。

**想发给别人看？** 把这个文件夹上传到任意静态托管（GitHub Pages、Vercel、Netlify、对象存储等）即可获得一个网址。注意每个人的浏览器里是各自的数据，别人打开看到的是 `posts.js` 里的内容；所以写完文章要先「导出发布文件」再上传，具体步骤见 [部署到GitHub.md](部署到GitHub.md)。

## 五、小细节

- **阅读进度**：文章页顶部有一条渐变进度条，随滚动增长。
- **右侧目录**：根据 `##` / `###` 自动生成，滚动时高亮当前章节，点击可平滑跳转（窄屏自动隐藏）。
- **搜索**：首页搜索框按 `/` 可快速聚焦，可搜标题、摘要、标签和正文。
- **标签筛选**：点标签胶囊即可筛选，再点「全部」恢复。
- **复制**：文章页可一键复制链接；代码块右上角可复制代码。
- **置顶**：编辑器里勾选「置顶」，该文章会出现在首页顶部的大卡片里。
- **打印 / 存 PDF**：在文章页直接 `Ctrl / Cmd + P`，会自动隐藏侧栏与界面元素，只打印正文。
- **无障碍**：表单有标签、抽屉与弹窗有 `aria` 属性，键盘 `Esc` 可关闭抽屉 / 侧栏。

## 七、常见问题

**Q：文章里的图片怎么加？**
A：用 Markdown 图片语法 `![说明](https://…/photo.jpg)`，支持任意可访问的图片地址。当前版本不做本地图片上传（避免撑爆浏览器存储）。

**Q：刷新后草稿还在吗？**
A：在。草稿和已发布文章一样会实时写入本地存储，写作台里标为「草稿」。

**Q：能多个人一起写吗？**
A：当前是单人本地博客，没有账号与后端；多人协作需要接数据库或静态站点生成器。

**Q：为什么首页文章数和列表数不一样？**
A：置顶 / 最新的一篇会单独显示成顶部大卡片，其余文章在下方列表，所以列表标题写的是「更多文章」。

**Q：浏览器兼容性？**
A：Chrome / Edge 100+、Safari 16+、Firefox 110+。极老浏览器不支持 `color-mix()` 时会退回纯色主题。

**Q：数据丢了怎么办？**
A：先看是否换了浏览器或无痕模式；如果之前导出过备份，用「导入备份」恢复。建议每次大改后导出一次。
